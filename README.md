# Recruiter AI v0.1 — Investor Demo

Автономный AI-агент для автоматизации подбора персонала. Демонстрационная версия B2B SaaS-продукта.

## Стек технологий

- **React 19** + **TypeScript** (strict mode)
- **Tailwind CSS 4** — утилитарные стили
- **Wouter** — клиентская маршрутизация
- **Recharts** — графики и аналитика
- **Lucide React** — линейные иконки
- **Framer Motion** — анимации
- **shadcn/ui** — базовые UI-компоненты
- **localStorage** — сохранение демо-изменений

## Быстрый старт

```bash
# Установка зависимостей
pnpm install

# Запуск в режиме разработки
pnpm dev

# Production-сборка
pnpm build

# Запуск production-версии
pnpm start
```

## Mock-данные

Все данные вымышленные и находятся в `client/src/data/`:

- 3 вакансии (Менеджер B2B, Руководитель продаж, Поддержка)
- 12 кандидатов с полными резюме и AI-анализом
- 5 AI-интервью с вопросами и ответами
- 27 событий активности AI
- 7 интеграций (демонстрационные)
- Аналитические данные для графиков

## Демонстрационный сценарий

1. **Обзор** → статистика, Центр управления AI, прогресс
2. **Создание вакансии** → 4-шаговая форма → запуск AI (анимация)
3. **Список вакансий** → фильтры, поиск, открытие деталей
4. **Кандидаты** → таблица, фильтры, статусы
5. **Карточка кандидата** → 7 вкладок (обзор, резюме, AI-анализ, переписка, интервью, файлы, история)
6. **Решение HR** → изменение статуса с подтверждением
7. **AI-интервью** → структурированные вопросы и ответы
8. **Активность AI** → лента событий с группировкой по дате
9. **Аналитика** → графики воронки, скорости, источников
10. **Интеграции** → карточки с демо-статусами
11. **Настройки** → компания, профиль, AI-параметры

## Интерактивность

- Навигация между всеми страницами
- Создание новой вакансии с сохранением в localStorage
- Изменение статуса кандидата (с подтверждением для опасных действий)
- Приостановка/продолжение задачи AI
- Фильтрация и поиск кандидатов/вакансий
- Переключение вкладок в карточке кандидата
- Сброс демо-данных в настройках

## Подключение backend (будущее)

Для замены mock-данных настоящим API:

1. Создайте API-сервер (Node.js/Python/Go)
2. Замените импорты из `data/` на fetch-запросы
3. Замените `localStorage` на серверное хранилище
4. Подключите реальный AI API для анализа
5. Добавьте аутентификацию

Архитектура готова к постепенной замене — все данные типизированы, состояние централизовано.
